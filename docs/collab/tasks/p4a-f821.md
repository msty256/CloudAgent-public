## 为什么单独出这一张卡

`ruff check cloudagent_ext tests` 当前报 **3 个 error，全部是 F821**：

```
cloudagent_ext\agent\registry.py:159:36: F821 Undefined name `Any`
tests\diagnosis\test_session_wiring.py:685:37: F821 Undefined name `pathlib`
tests\diagnosis\test_session_wiring.py:685:65: F821 Undefined name `pathlib`
```

这**与评测体系无关**，是产品仓的既有小缺陷。两行就能清零，
不该被"评测体系大工程"阻塞。修完 `ruff check` 全绿，CI 才有意义。

⚠️ 这三处因为 `from __future__ import annotations` 而在**运行时无害**（注解不求值），
所以不影响功能——但它们是真实的名字错误，且会让 `ruff` 永远红着，
以后真正的 lint 问题会被这条噪音掩盖。

## 具体改法

**1. `cloudagent_ext/agent/registry.py:53`**

当前：
```python
from typing import TYPE_CHECKING, Callable
```
改为：
```python
from typing import TYPE_CHECKING, Any, Callable
```

（`Any` 在 `:159` 的 `Callable[[Any], bool]` 用到，目前只在注解里，所以运行不炸。）

**2. `tests/diagnosis/test_session_wiring.py`**

文件头（`:18-22` 附近）已有 `import asyncio / import json / import threading`，
加一行：
```python
import pathlib
```
然后 `:685` 的 `def _transcript(self, tmp_path: pathlib.Path, text: str) -> pathlib.Path:`
保持原样（加了导入后 `pathlib` 就解析得到了）。

> 也可以改成 `from pathlib import Path` 并把两处 `pathlib.Path` 改 `Path`——
> 但那是 **两处改动 vs 一处**，而且会动到签名行。**选改动最小的**（加导入）。
